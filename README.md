# Partially Signed Bitcoin Transactions

Implementation of the Partially Signed Bitcoin Transaction (PSBT) Format as
defined in [BIP-174] and PSBT version 2 as defined in [BIP-370].

The canonical repository is at [git.rust-bitcoin.org][repo].
A read-only remote exists on [GitHub].

[BIP-174]: <https://github.com/bitcoin/bips/blob/master/bip-0174.mediawiki>
[BIP-370]: <https://github.com/bitcoin/bips/blob/master/bip-0370.mediawiki>
[repo]: <https://git.rust-bitcoin.org/rust-bitcoin/rust-psbt>
[GitHub]: <https://github.com/rust-bitcoin/rust-psbt>
